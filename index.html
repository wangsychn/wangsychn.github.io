Worlds

三つの世界

主世界、ネザー、エンドのすべてに専用のワールド生成を導入。いつものサバイバルに、探索する楽しさをもう一度加えています。

Terra

主世界

自然な地形と大きな景観を持つ、拠点づくりと長期開拓の中心。

Incendium

ネザー

危険なバイオームと構造物が広がる、緊張感のあるネザー。

Nullscape

エンド

虚空に浮かぶ異質な地形を旅する、静かで壮大なエンド。

Features

UJIMC の特徴

純粋なサバイバルの手触りを残しつつ、キャンパス発のコミュニティとして遊びやすさと自由度を整えています。

  • Java / Bedrock クロスプレイ 好きなエディションから参加可能。バージョン自由、推奨は Java 26.1.2。
  • 純サバイバル中心 経済や重い独自システムで縛らず、建築・探索・生活を自分のペースで楽しめます。
  • 三つの生成世界 Terra、Incendium、Nullscape が、見慣れた三次元をもう一度新鮮にします。
  • 便利な機能 warp、飛行許可、地震速報など、生活を支える実用的で少し楽しいプラグインがあります。
  • 宇治キャンパス発 サーバー所在地は宇治キャンパス。大学メールアドレスがあればホワイトリスト登録できます。
  • 多言語コミュニティ 学内外のプレイヤーが、日本語・中文・English を交えて遊んでいます。
